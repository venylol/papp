## Egaroucid worker 运行约束

`third_party\player-analysis-toolkit\src\player_analysis_toolkit\egaroucid_worker_budget.py` 是本地 Egaroucid 启动入口共用的约束模块：比赛运行使用最多 2 个 worker；后台选手调查按 `floor(50% × 物理内存 / 1400 MiB)` 计算 worker 上限。跨进程 slot 锁让两类任务共享 50% 物理内存池；超限请求直接拒绝。
